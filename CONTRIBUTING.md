# Contributing

Bug reports and focused improvements are welcome. For a larger change, open an issue first so the scope can be discussed.

Before submitting a pull request:

1. Keep changes focused and avoid including build outputs, credentials, or local configuration.
2. Run the checks relevant to the files you changed. For macOS, see the test command in the root README; for Windows, follow [Windows build instructions](Windows/README.md).
3. Describe the user-visible change and the checks you ran.

By contributing, you agree that your contribution is provided under the repository's [MIT License](LICENSE).
