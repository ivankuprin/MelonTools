# Melon Tools 2.2.1

- **Fixed shared models disappearing from provider sections.** When the same
  model is offered by two providers (for example Gemini 3.5 Flash Lite from
  OpenCode and Antigravity), Codex collapsed the rows because their display
  names matched. Colliding names now include the provider, so the model stays
  visible under both providers.
- No other changes.

## Downloads

- [macOS universal DMG](https://github.com/ivankuprin/MelonTools/releases/latest/download/MelonTools-2.2.1.dmg) — macOS 14 or later, Apple Silicon and Intel.
