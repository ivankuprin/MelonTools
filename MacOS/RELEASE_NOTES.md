# Melon Tools 2.2.2

- **Shared models now refresh automatically.** macOS rebuilds the Codex model
  catalog on every launch, not only when the selected model ids change. The
  provider-qualified display names from 2.2.1 therefore appear immediately
  after updating, without pressing Apply again.
- No other changes.

## Downloads

- [macOS universal DMG](https://github.com/ivankuprin/MelonTools/releases/latest/download/MelonTools-2.2.2.dmg) — macOS 14 or later, Apple Silicon and Intel.
- [Windows installer](https://github.com/ivankuprin/MelonTools/releases/latest/download/MelonTools-2.2.2-setup.exe) — custom install path, WebView2 required.
- [Windows portable](https://github.com/ivankuprin/MelonTools/releases/latest/download/MelonTools-2.2.2-win-x64-portable.exe) — single file, no install.
