# Melon Tools for Windows

Порт приложения на **Tauri 2** (Rust + WebView2). Версия **1.4.8**.

Готовая сборка **Windows x64** доступна в [последнем релизе](https://github.com/ivankuprin/MelonTools/releases/latest/download/MelonTools-1.4.8-win-x64.exe) — или обновитесь прямо из приложения: сайдбар → **«Обновить»**.
Скачайте и запустите `.exe`; это приложение, не установщик. Для запуска нужен
**WebView2 Runtime**. Файл не подписан Authenticode, поэтому Windows может
показать предупреждение. SHA-256 опубликован рядом с файлом; в PowerShell
проверьте его командой:

```powershell
Get-FileHash .\MelonTools-1.4.8-win-x64.exe -Algorithm SHA256
```

Исходники и инструкции по сборке приведены ниже.

## Что умеет эта сборка

- **Шлюз (API Service)**: запуск/остановка/перезапуск локального OpenAI-совместимого
  шлюза на `http://127.0.0.1:18317/v1`, ключ доступа, сквозная проверка (маленький
  запрос через пул), живой счётчик «Запросов/мин» из журнала.
- **Аккаунты (пул ChatGPT)**: карточки с квотами 5 ч / неделя (полоса + процент +
  обратный отсчёт сброса), пауза по резерву (например, 5%), переключатель
  «Сделать текущим» — пишет `%USERPROFILE%\.codex\auth.json` в **полном формате**
  (`auth_mode` + `tokens.account_id` — фикс из macOS 1.4.5), обновление логина и
  квоты, удаление.
- **Живая синхронизация с шлюзом**: пауза/разблокировка по квотам пишется в
  auth-файлы шлюза сразу после обновления квот (сигнатура доступности).
- **Провайдеры**: метрики ключа OpenRouter (куплено/потрачено/остаток/лимит ключа),
  ключи OpenCode/OpenRouter попадают в конфиг шлюза (после перезапуска шлюза
  появляются модели `opencode/*` и `openrouter/*`).
- **Настройки**: язык RU/EN, порт шлюза, интервал автообновления квот.
- **Донат**: USDT (TRC20) с копированием адреса.

## Где лежат данные

```
%APPDATA%\MelonTools\
├── codex\accounts.json     ← vault аккаунтов (формат совместим с macOS-версией)
├── settings.json           ← настройки
└── gateway\
    ├── config.yaml         ← конфиг CLIProxyAPI
    ├── auths\*.json        ← аккаунты для шлюза (пауза = "disabled": true)
    └── gateway.log         ← журнал шлюза
```

Vault можно перенести с macOS: скопируйте
`~/Library/Application Support/MelonTools/codex/accounts.json`
в `%APPDATA%\MelonTools\codex\accounts.json` — аккаунты и подписки подхватятся.

## Интеграция с Codex

- **Route Codex** — приложение пишет `%USERPROFILE%\.codex\config.toml`
  (`model_provider = "melon_local_access"` + провайдер с bearer-токеном),
  так что Codex ходит через локальный шлюз. Настраивается автоматически при
  запуске шлюза и кнопкой на странице API; снимается кнопкой там же. Бэкап
  исходного файла: `config.toml.melon-backup`.
- **Каталог моделей** — `melon-model-catalog.json` собирается из базового
  каталога + живого списка моделей шлюза (модели `opencode/*` и
  `openrouter/*` добавляются в пикер сгруппированно).
- **Чипы в композере** — мост подключается к Codex через DevTools-протокол
  (как на macOS): аккаунты, квоты 5ч/неделя, запросы/мин. Для работы Codex
  должен быть запущен с debug-портом — кнопка **«Перезапустить Codex с
  чипами»** на странице API делает это автоматически. Состояние моста
  (подключён/нет и причина) видно в карточке «Интеграция с Codex».

## Текущие ограничения Windows-порта

- **Fleet — базовая версия**: снимки, журнал, результаты (просмотр), конфиг
  и запуск CLI (`status`/`doctor`). Стриминговые консоли «звонков» (Call) и
  редактор правил — в разработке.
- **Расход сессии в чипах**: показываются токены и число ходов из rollout-файла
  Codex; оценка стоимости (прайс-таблица моделей) — следующий шаг.
- **Модели в чипах**: метрики провайдеров (OpenRouter) в поповере — следующий шаг.

## Сборка из исходников (macOS или Windows)

Исходники: `app/` (`ui/` — фронтенд без сборки, `src-tauri/` — Rust).

На macOS для кросс-сборки (см. `build-windows.sh`):

```bash
rustup target add x86_64-pc-windows-msvc
cargo install cargo-xwin --locked
brew install lld llvm
./build-windows.sh
```

На Windows установите Rust и Tauri CLI, затем выполните `cargo tauri build` из
`app/`. Сборка использует включённый в репозиторий сжатый движок шлюза.

## Технические детали

- Движок: CLIProxyAPI (Go), собран под `windows/amd64`, конфиг 1:1 с macOS-версией
  (`fill-first`, retry 3, disabled-флаг для пауз). Движок **встроен в exe** в
  сжатом виде (zlib, ~23 МБ) и распаковывается в `%APPDATA%\MelonTools\engine\`
  при первом запуске или после обновления версии.
- Фронтенд: ванильный HTML/CSS/JS, дизайн-токены перенесены из `MTTheme.swift`
  (палитра, отступы, карточки, золото).
- Сеть: reqwest (native-tls → schannel на Windows), без OpenSSL.
- Чипы: CDP через WebSocket (`tokio-tungstenite`), тот же `composer-chips.js`,
  что и на macOS.
